# Farō Reader

Farō Reader legge i libri ad alta voce e accende la parola che sta leggendo.
È pensato per chi ha dislessia e funziona senza internet. È una delle applicazioni del progetto **Farō**.

Questo repository è la parte pubblica del progetto:

| Cosa cerchi | Dove |
|---|---|
| Scaricare l'app | pagina **Releases** |
| Il sito, con la filosofia e le regole del progetto | cartella `docs/` (pubblicata come sito) |
| Segnalare un errore o proporre un'idea | scheda **Issues** |
| Farsi la propria voce (parte non ufficiale) | [`voci/GUIDA.md`](voci/GUIDA.md) |

Il codice dell'applicazione non è in questo repository.
